# Yandex Tracker — коннектор для Claude

Коннектор к [API Яндекс Трекера](https://yandex.ru/support/tracker/ru/about-api) (v3): Claude ищет и читает задачи, создаёт и правит их, меняет статусы, пишет комментарии, связывает задачи, списывает время и работает с вложениями — от имени владельца токена. Любой другой метод API (доски, спринты, проекты, массовые изменения) доступен прямыми запросами.

Коннектор стоит на сервере за [шлюзом коннекторов](https://github.com/sergei-grigorov/mcp-gateway), по адресу `https://agent.sergei-grigorov.com/tracker`, и работает в claude.ai, приложениях Claude и Claude Code. Его можно поставить и локально в Claude Desktop — пакетом MCPB.

## Что умеет

- **Поиск.** Язык запросов Трекера (`Assignee: me() Resolution: empty() "Sort by": Updated DESC`), фильтр по полям, ключи, очередь, сохранённый фильтр; постранично, с общим числом. Только подсчёт — `count_only`.
- **Задача целиком.** Все поля, включая локальные поля очереди, описание, чек-лист; по запросу — комментарии, доступные переходы, связи, вложения, списанное время, история изменений. Ответы сжаты: ссылки на пользователей, статусы и очереди — одной строкой вида «Иван Петров (1130000012345)», «В работе (inProgress)».
- **Изменения.** Создание задачи (очередь по умолчанию, свои поля, ключ идемпотентности), правка полей (теги и наблюдатели — добавить/убрать), смена статуса по названию целевого статуса или id перехода — с резолюцией и комментарием, комментарии в Markdown с призывом коллег, правка комментария, связи, учёт времени («1h 30m» → PT1H30M), приложение файла.
- **Справочники.** Очереди; очередь подробно — типы задач, рабочие процессы, резолюции, компоненты, версии, локальные поля; поля с типами и значениями; поиск пользователей по имени, логину, почте.
- **Вложения.** Текстовые файлы открываются текстом, картинки — картинками.
- **Любой метод API.** `send_read_request` — GET и поисковые POST (`…/_search`, `…/_count`, `…/_find`); `send_write_request` — POST, PATCH, PUT и (если разрешено) DELETE.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `connector_status` | Настройки, организация, чей токен (проверка запросом `/v3/myself`) |
| `search_issues` | Поиск задач |
| `get_issue` | Задача целиком, по запросу — комментарии, переходы, связи, вложения, время, история |
| `create_issue` | Создать задачу |
| `update_issue` | Изменить поля |
| `change_status` | Сменить статус; без цели — список доступных переходов |
| `add_comment`, `edit_comment` | Комментарии |
| `link_issues` | Связать задачи |
| `log_work` | Списать время |
| `list_queues`, `get_queue`, `list_fields`, `find_users` | Справочники |
| `get_attachment`, `attach_file` | Вложения |
| `send_read_request`, `send_write_request` | Любой метод API |

Имена — действия без приставки, как у коннекторов Bybit, Telegram и Ubuntu: в чате рядом с вызовом и так видно, чей это инструмент.

## Настройки

| Поле | Что это |
|---|---|
| **OAuth-токен** | Токен Яндекса с доступом к Трекеру (см. ниже). IAM-токен Yandex Cloud (`t1.…`) тоже подойдёт, но живёт 12 часов. |
| **ID организации** | Трекер → Администрирование → Организации. Яндекс 360 — число, Yandex Cloud — строка вида `bpf…`. |
| **Тип организации** | `360` (заголовок `X-Org-ID`) или `cloud` (`X-Cloud-Org-ID`). Пусто — по виду ID. |
| **Очередь по умолчанию** | Для новых задач, если Claude не указал другую. |
| **Разрешить изменения** | По умолчанию включено. Выключено — остаются только инструменты чтения. |
| **Разрешить удаление** | По умолчанию выключено: `DELETE` через `send_write_request` недоступен. |

На сервере настройки меняются на странице `https://agent.sergei-grigorov.com/tracker/settings` (нужен вход владельца шлюза) и применяются сразу. Локально — Settings → Extensions → Yandex Tracker в Claude Desktop.

### Как получить OAuth-токен

1. На [oauth.yandex.ru](https://oauth.yandex.ru/client/new) создайте приложение: платформа «Веб-сервисы», Redirect URI — `https://oauth.yandex.ru/verification_code`, доступы Трекера — «Чтение из трекера» и «Запись в трекер» (`tracker:read`, `tracker:write`).
2. Откройте `https://oauth.yandex.ru/authorize?response_type=token&client_id=<ClientID приложения>` под учётной записью, от имени которой будет работать Claude, и скопируйте токен.
3. Вставьте токен и ID организации в настройки коннектора, затем попросите Claude вызвать `connector_status` — он покажет, чей это токен.

Токен даёт те же права в Трекере, что у его владельца. Отозвать его можно на [id.yandex.ru](https://id.yandex.ru/security) → «Устройства и сервисы» (или удалив приложение).

## Безопасность

- **Токен** хранится в настройках коннектора (на сервере — `data/tracker/settings.json`, права 0600) и уходит только в API Трекера. В ответы Claude попадают лишь его последние 4 символа.
- **Запросы только в API Трекера.** Путь прямого запроса — относительный (`/v3/…` или `/v2/…`), без схемы, хоста и `..`; адрес API нельзя подменить на http.
- **Изменения видны коллегам** — они делаются от имени владельца токена. Описания инструментов требуют от Claude подтверждения пользователя перед изменением задач, которые тот не назвал явно, и перед массовыми изменениями. Правила продублированы в описаниях инструментов: claude.ai не передаёт модели инструкции сервера.
- **Тексты задач, комментариев и вложений** — данные, а не инструкции: об этом сказано в описаниях инструментов чтения.
- **Удаление** выключено по умолчанию, изменения можно выключить целиком.

## На сервере

`server/serve.js` — MCP по HTTP за шлюзом: принимает запросы только с секретом шлюза (`X-Gateway-Secret`), MCP — только с токеном OAuth шлюза, страницу настроек — только владельцу. Контейнер `tracker` в `mcp-gateway/deploy/docker-compose.yml`: `node:24-alpine`, файловая система только для чтения, данные — `data/tracker`. Выкладка — `deploy/deploy.sh` шлюза вместе с остальными коннекторами.

Переменные окружения: `PUBLIC_URL` (`https://agent.sergei-grigorov.com/tracker`), `GATEWAY_SECRET`, `DATA_DIR`, `HOST`, `PORT`; кроме того, `TRACKER_API_URL`, `TRACKER_TIMEOUT_MS` (30000), `TRACKER_LOG_LEVEL`.

## Ограничения

- Список пользователей для `find_users` загружается целиком (до 20 000) и кешируется на 5 минут.
- Выдача поиска — постраничная (до 10 000 задач); больше — прокруткой через `send_read_request` (`scrollType`, `scrollId`).
- Вложения открываются только текстовые (до 100 000 символов) и картинки PNG, JPEG, GIF, WebP до 5 МБ; прикладываются файлы до 20 МБ.

## Разработка

```bash
npm test            # тесты против поддельного API Трекера
npm run validate    # проверка manifest.json
npm run pack        # пакет dist/yandex-tracker.mcpb для Claude Desktop
```

Зависимостей нет, нужен Node.js 22+. `server/mcp.js`, `server/log.js` и `server/remote/` — общие с коннектором Ubuntu: правки переносить в оба.
